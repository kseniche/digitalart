# Цифровое искусство

Веб-приложение — блог о цифровом искусстве и компьютерной графике. Пользователи публикуют работы (изображения и видео), комментируют, подписываются на авторов и сохраняют избранное. Администраторы модерируют контент, управляют пользователями и смотрят аналитику.

**Стек:** Laravel 12 (PHP 8.2+), React 19 (Vite 7), MySQL или SQLite, Laravel Sanctum, Spatie Permission.

---

## Возможности

### Для гостей и пользователей

- Лента публикаций с фильтрами по категории, тегу и сортировке
- Просмотр публикации, лайки, избранное, комментарии (с модерацией)
- Профили авторов: портфолио, черновики, подписки
- Создание публикаций: Markdown-описание, теги, отложенная публикация, черновики
- Автомодерация текстов по словарю запрещённых слов
- Внутренние уведомления в интерфейсе (и email для отдельных событий)

### Для администраторов (`/admin`)

- Дашборд со счётчиками и графиками аналитики
- Управление пользователями (блокировка, удаление, восстановление)
- Модерация публикаций и комментариев, жалобы
- Категории и теги
- Экспорт отчётов в CSV

## Быстрый старт

Полная пошаговая инструкция — в [install.md](install.md).

```bash
composer run setup
php artisan db:seed
php artisan storage:link
composer run dev
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

После `db:seed` доступен администратор:

| Поле | Значение |
|------|----------|
| Email | `admin@digital-art.ru` |
| Пароль | `password123` |

## Разработка

| Команда | Назначение |
|---------|------------|
| `composer run dev` | Сервер, очередь, логи и Vite одновременно |
| `php artisan serve` | Только backend |
| `npm run dev` | Только фронтенд (hot reload) |
| `npm run build` | Production-сборка в `public/build` |
| `composer run test` | PHPUnit-тесты |

Для загрузки медиа до 50 МБ в dev-режиме `composer run dev` поднимает PHP с `upload_max_filesize=64M` и `post_max_size=64M`.

## Структура проекта

```
app/                    # Backend: контроллеры, сервисы, модели
config/                 # Конфигурация (уведомления, автомодерация, S3)
database/               # Миграции и сидеры
resources/js/           # React SPA (компоненты, маршруты)
resources/css/          # Стили
routes/api.php          # REST API
routes/web.php          # SPA fallback
tests/                  # Feature, Unit, Browser (Dusk)
docs/pz.txt             # Пояснительная записка (дипломный проект)
```
