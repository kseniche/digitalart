# Цифровое искусство 
# Выполнил: Чеботарёва Ксения Евгеньевна
# Группа:ВЕБ22-1
Информационная система для публикации, просмотра и обсуждения цифровых художественных работ с административной панелью управления.

## Функциональность

Платформа «Цифровое искусство» - это информационная система для художников, которое позволяет:
- Публиковать свои работы с описаниями и тегами
- Просматривать работы других художников
- Ставить лайки и оставлять комментарии
- Управлять своим профилем и портфолио
- Подписываться на других пользователей
- Администрировать контент и пользователей

## Основные возможности

### Для пользователей

#### Главная страница
- Лента публикаций с адаптивной сеткой
- Фильтрация: популярные / новые публикации
- Поиск по названию, автору и тегам
- Превью изображений с сохранением пропорций

#### Публикации
- Просмотр работ в полном размере
- Система лайков
- Комментарии с отображением аватаров
- Теги для категоризации
- Информация об авторе с возможностью перехода в профиль

#### Профиль пользователя
- Редактирование личной информации
- Загрузка аватара
- Добавление информации: город, страна, веб-сайт, биография
- Портфолио с отображением всех публикаций
- Статистика: количество подписчиков и подписок
- Система подписок

#### Создание публикаций
- Загрузка изображений (JPEG, PNG, GIF, WebP до 10MB)
- Предпросмотр изображения 
- Добавление названия, описания и тегов

#### Настройки профиля
- Редактирование персональных данных
- Валидация форм (email, телефон, веб-сайт)
- Обновление аватара

### Для администраторов

#### Административная панель
- Общая статистика системы
- Управление пользователями (просмотр, удаление, восстановление)
- Управление публикациями (просмотр, удаление, восстановление)
- Управление комментариями (просмотр, удаление, восстановление)
- Поиск и фильтрация во всех разделах
- Генерация отчетов в формате CSV

#### Отчеты
- Общая статистика (пользователи, публикации, комментарии)
- Детальная информация о всех пользователях
- Детальная информация о всех публикациях
- Детальная информация о всех комментариях
- Экспорт в CSV

##  Установка

### Требования
- PHP 8.2 или выше
- Composer 2.x
- Node.js 18.x или выше
- npm или yarn
- MySQL


### Шаг 1: Клонирование репозитория
```bash
git clone <repository-url>
cd digital-art
```

### Шаг 2: Установка зависимостей

#### PHP зависимости
```bash
composer install
```

#### Node.js зависимости
```bash
npm install
```

### Шаг 3: Настройка окружения

1. Скопируйте файл окружения:
```bash
cp .env.example .env
```

2. Сгенерируйте ключ приложения:
```bash
php artisan key:generate
```

3. Настройте `.env` файл:
```env
APP_NAME="Цифровое искусство"
APP_URL=http://localhost:8000

DB_CONNECTION=sqlite

# Для MySQL укажите параметры подключения

# S3 хранилище (SelectelCloud или аналог)
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
AWS_DEFAULT_REGION=ru-1
AWS_BUCKET=your_bucket_name
AWS_ENDPOINT=https://s3.ru-1.storage.selcloud.ru
AWS_USE_PATH_STYLE_ENDPOINT=true
AWS_URL=https://your_bucket_name.s3.ru-1.storage.selcloud.ru
```

### Шаг 4: База данных

1. Создайте базу данных:
```bash
# Для SQLite база создастся автоматически
touch database/database.sqlite

# Для MySQL создайте базу вручную
```

2. Выполните миграции:
```bash
php artisan migrate
```

3. Заполните базу тестовыми данными:
```bash
php artisan db:seed
```

Будут созданы:
- **Администратор**: admin@admin.com / password
- **Тестовые пользователи**: test1@test.com - test5@test.com / password
- **Публикации**: 6 тестовых публикаций с изображениями

### Шаг 5: S3 хранилище 

#### Подготовка изображений
1. Загрузите изображения в папку `posts/` вашего S3 бакета
2. Необходимые файлы:
   - `digital-art-1.jpg`
   - `3d-art-2.png`
   - `vector-art-3.jpg`
   - `photo-manipulation-4.jpg`
   - `pixel-art-5.jpg`
   - `concept-art-6.jpg`

#### Проверка подключения
```bash
# Проверка конфигурации
php artisan config:check

# Полное тестирование S3
php artisan s3:test
```

### Шаг 6: Запуск приложения

#### Вариант 1: Для разработки
```bash
# Терминал 1 - Laravel сервер
php artisan serve

# Терминал 2 - Vite dev server
npm run dev
```

Откройте браузер: http://localhost:8000

#### Вариант 2: Для продакшена

##  API Endpoints

### Публичные маршруты
```
GET    /api/feed                    # Лента публикаций
GET    /api/posts                   # Список публикаций
GET    /api/posts/{id}              # Детальная информация о публикации
GET    /api/profiles/{id}           # Профиль пользователя
GET    /api/profiles/{id}/posts     # Публикации пользователя
POST   /api/login                   # Авторизация
POST   /api/register                # Регистрация
```

### Защищенные маршруты (требуют аутентификации)
```
GET    /api/user                    # Текущий пользователь
POST   /api/logout                  # Выход

# Публикации
POST   /api/posts                   # Создание публикации
PUT    /api/posts/{id}              # Редактирование публикации
DELETE /api/posts/{id}              # Удаление публикации

# Взаимодействие
POST   /api/posts/{id}/like         # Лайк/дизлайк публикации
POST   /api/posts/{id}/comments     # Добавление комментария
DELETE /api/comments/{id}           # Удаление комментария

# Профиль
GET    /api/profile                 # Текущий профиль
PUT    /api/profile                 # Обновление профиля
POST   /api/profile/avatar          # Обновление аватара

# Подписки
POST   /api/users/{id}/follow       # Подписаться/отписаться
GET    /api/users/{id}/follow-status # Статус подписки
```

### Админ-панель (только для администраторов)
```
GET    /api/admin/stats             # Общая статистика
GET    /api/admin/report            # Генерация отчета (CSV)

# Пользователи
GET    /api/admin/users             # Список пользователей
GET    /api/admin/users/{id}        # Детальная информация
DELETE /api/admin/users/{id}        # Удаление пользователя
POST   /api/admin/users/{id}/restore # Восстановление пользователя

# Публикации
GET    /api/admin/posts             # Список публикаций
DELETE /api/admin/posts/{id}        # Удаление публикации
POST   /api/admin/posts/{id}/restore # Восстановление публикации

# Комментарии
GET    /api/admin/comments          # Список комментариев
DELETE /api/admin/comments/{id}     # Удаление комментария
POST   /api/admin/comments/{id}/restore # Восстановление комментария
```
